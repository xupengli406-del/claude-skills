# 电脑录屏与资料讲解（杂志风）

主要观看对象是实际电脑操作、引用原片、文章或资料；真人小窗可有可无。默认暖灰黑杂志风，资料型横屏沿用已认可的资料主区、右侧补充、右下可选真人及底部双语区。读[屏幕构图](references/screen-layout.md)，明确的新要求与本期已选方案优先。不是因为坐在电脑前或出现人脸就选本流程。

## 先确定范围与阶段

按[分流与混合片](references/video-routing.md)判断一次负责人。真人现场和观点为主时由真人随手拍负责；明确连续手绘画板、多人访谈、数字人时保留专项。两包不递归调用对方整套流程。只改字幕、封面、某段操作或已选布局时，只改授权层。

- 只有选题/草稿：读[教程组织](references/tutorial-planning.md)和[写稿](references/scriptwriting.md)，先交可直接念的稿及稿外录制清单；标清待演示与已实测，不能虚构点击、运行结果、账号权限或新旁白。确认稿件后等实际素材，不自动生成音视频。
- 有真实录屏、正式讲解录音或本人画中画：直接进入制作，不重复稿件确认。以实际原声和操作为准，保护真实界面、鼠标、输入、等待和输出的因果顺序。
- 延续项目：读取当前工程、时钟、已选画面与修改点；历史参考只是布局或方法依据，不自动成为本片事实。

## 从素材到完整交付

1. **建立教程输入。** 核实实际录屏/引用原片/资料、可选本人录像和录音、目标观众及希望完成的任务。读取分辨率、方向、帧率、音轨、时长和源文件路径，保留原件。按[教程组织](references/tutorial-planning.md)列输入→实际操作→真实结果→验收，缺关键步骤时只记录待录，不能用假界面补齐。完整片读[目标与复盘](references/performance-review.md)确定第一处真实收获。
2. **定原声与三秒钩子。** 读[开头](references/opening-and-retention.md)与[剪辑声音](references/editing-and-audio.md)，0–3秒内用有依据的真实结果、问题或反差建立观看理由，立即接回条件与操作。先做自然精剪，保留理解结果必需的准备、参数、失败提示和限定；实际等待可压缩并标明，不把跳剪伪装实时完成。保存源片到成片映射，所有画面、本人小窗、字幕和动作使用同一母音频/成片时钟。
3. **组织资料与操作主屏。** 读[屏幕构图](references/screen-layout.md)、[屏幕动作](references/screen-motion.md)和[真实资料](references/icon-motion-design.md)。横屏按已确认网格起排，竖屏重新组织可读结构，不把整张桌面压成邮票。标题、侧栏只给当前任务及后文仍需的信息，不复制字幕或塞满维护说明。本人小窗不遮实际目标，没必要时可不出现；不强加固定VS、人名、日期、倍速或时长。完整上下文→真实目标同位置聚焦→动作/反馈→停稳结果→回全景，鼠标按真实坐标与时钟走；V30步骤页只做入口，不替代关键点击/输入/输出。长图保留完整来源及当前阅读位置。
4. **引用与陪看。** 主要是原片/资料解读时读[屏幕陪看](references/screen-commentary.md)，先保留支撑观点的提问、例子和必要条件；本人解释时原片通常暂停并静音，低信息背景例外按[声音状态](references/audio-state-and-mapping.md)。原片时钟、本人时钟和成片时钟分开记录，冻结原片不冻结本人。混合真人段仍在本包按人物构图处理，不新造第二套声音或发布包。
5. **双语字幕与语义动作。** 默认[双语](references/bilingual-subtitles.md)并交三份SRT，先核对最终中文再翻译。按[字幕与动效](references/subtitles-and-motion.md)接入本包V24组件：整句普通初态→实际发声锚点放大→邻字平滑让位→整句退出前保持→下一条重建；顺播、随机seek、分段一致。让真实材料与语义动作承担理解，不把全部变化缩成侧栏文字或金框。动作与颜色按[共同规则](references/visual-principles.md)，原声没有的事实或关系不能由图形编出来。
6. **导出、封面和发布包。** 新布局、明显变速或复杂动作先内部检查代表片段，再完成整片，不以样片代替全片。按[封面](references/covers-and-release.md#cover-default)当前中央漫画分格方向及[四平台](references/four-platform-delivery.md)完成独立三比例封面、四平台文案、三份字幕、所需来源/声明和当前成片章节。封面单独构图，不为配封面改变视频比例。按[验收交付](references/review-and-handoff.md)看听实际导出：0–3秒到第一观点、所有关键操作/提示/结果、剪口、口型和音轨、最长字幕、V24前中后/句末/下一条与结尾；以1×和手机尺度检查。文件/代码检查不能当完整视听或用户接受。

## 本包工具与质量边界

[共同质量](references/quality-standards.md)落实真实声音、三秒钩子、V24与实际导出标准；[屏幕选择记录](references/screen-requirements.md)保留已认可构图的适用范围。39方法、8配方与V24/V30/V31全部在[内置方法](references/editing-methods/index.md)，按[执行校验](references/editing-methods/execution.md)接入，不依赖另装真人Skill。14份原视频/截图证据是可选本地复核输入，公共包只带来源与哈希清单；历史教程不冒称新包端到端实测。

需要转录、拼接、普通SRT或烧录时读[源处理](references/source-editing.md)，使用本包 `scripts/source_editing/`，写当前项目或 `--workdir`。检查FFmpeg/FFprobe/Python，实际ASR才需Whisper；变速先重建映射，普通烧录不代替V24。V24代码组件位于本包 `assets/inline-emphasis.mjs`。视频工具按当前可用编辑器执行；用HyperFrames先读其当前入口。包内规范不依赖兄弟目录，渲染器、字体、原媒体、账号或付费工具须真实可用且获授权。

制作完整发布包不自动授权上传、充值、合成新发言或联系他人。交付说明真实做了什么和未检查的范围，保护当前作品与必要输入；替代已确认后可恢复清理本任务废稿并修正引用。
