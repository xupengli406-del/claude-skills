# 电脑录屏与资料讲解的暖灰黑杂志版式

本版式用于电脑操作、引用原片或资料为主要观看对象的教程与讲解，真人小窗可有可无。保留2026-10-15已认可的暖灰黑杂志风及资料型横屏网格；不作为所有真人随手拍的默认。既有作品局部返修保留其当前视觉，本期明确要求优先。

同日用户进一步指定以认可的“四小时对谈预告片”布局为资料型横屏内容的默认。此前规则已规定真实材料优先与对齐，但布局只描述主次和小窗，没有给几何；以下网格补足位置，取代随意拼接的“左侧大真人、右侧大文字卡”等布局。满屏口播、真实操作和竖屏的适用例外见下文。

## 资料型横屏的标准网格

参考取自当时认可的实际发布主片 `邵艾伦与孙宇晨_预告片_1080p.mp4`（64.533秒），并核对其1280×720工程及导出1.0、10.0、41.3秒画面。以下统一换算为1920×1080：左侧大资料主屏，右栏少量补充，本人右下小窗，字幕放在左主屏下方。参考片的双人照片、四小时／日期文案属于当片内容，不作为固定装饰复用。

| 区域 | 1920×1080坐标（x, y, 宽, 高） | 相对画布与使用约束 |
| --- | --- | --- |
| 主标题 | `66, 45, 1368, 99` | 左3.44%、上4.17%、宽71.25%；与资料左边缘对齐，短标题按真实字宽排布 |
| 顶部分隔线 | `66, 160.5, 1788, 3` | 横贯内容总宽93.13%，左右各66；不用额外页眉挤占资料 |
| 真实资料舞台 | `66, 207, 1368, 684` | 左3.44%、上19.17%、宽71.25%、高63.33%；素材等比适配，长图分区阅读，不拉伸 |
| 右栏标题／补充 | 标题 `1497, 225, 351, 64.5`；分隔线 `1497, 307.5, 348, 3`；正文从 `1497, 351` 开始 | 右栏左77.97%、宽18.28%；只放当前话题、必要总结或补充，正文止于约y666，与真人框留出间隔 |
| 真人外框 | `1476, 708, 378, 219` | 右下对齐总内容右缘1854；边6、圆角18，不能任意另移到资料左下 |
| 真人内容 | `1482, 714, 366, 207` | 约19.06%画布宽、19.17%画布高；等比取景，完整保住脸，不能拉伸或截下巴 |
| 主屏底分隔线 | `66, 936, 1368, 3` | 与主标题、资料舞台同宽，字幕独立留在其下，不贴在资料里 |
| 默认双语字幕安全区 | `66, 944, 1368, 114` | 中文行高72、英文行高42；均在左主屏范围内居中，不能按整幅画布居中而跨到真人下方 |

双语是对认可布局的安全适配：原参考只有单语，原字幕容器为 `0, 925.5, 1395, 105`、中文66px，不直接把两种语言硬塞进原105px容器。当前默认中文从52px、重点词最大约70px、英文30px开始；中文行y944–1016、英文行y1016–1058，普通透明字幕无底板。强调词放大后仍须完整落入中文行，英文保持稳定。长句先忠实简译或中英共同按语义拆cue；确需两行中文时共同调整字幕时点和主资料高度，保留真人避让，不能压到画布外或一路缩小字。字号是1080p起点，必须看手机尺度与最长句。

同一项目把这些区域集中定义为一组布局变量；主资料、标题、线条和字幕共用左边缘与宽度，右栏、真人共用右缘。分辨率变化按比例缩放，不逐段漂移。右栏没有实际补充就撤去文字与分隔线，并扩大主资料使用可用区域，不留空栏，也不编造词条填满。真人仍按右下锚点安排在非关键区域；若会挡证据，优先让证据完整可读，不为保留小窗牺牲内容。

## 视觉系统

- 暖黑背景、奶白资料面承接真实内容，可从背景 `#242321`、纸色 `#eee8dd` 与暖金 `#e9c36a` 起步；暖金不是全部标题、字幕和边框的统一指令。按[颜色角色与同屏焦点](visual-principles.md#调色角色与同屏焦点)区分底色、内容色、注释色和瞬时强调色，依据当前语义安排线重、对比、峰值和旧标记退场。真实录屏、原片、截图与人物保持原貌，不用全局暗幕改变证据。
- 中文正文使用可用且有授权的清晰黑体，长观点或标题可搭配中文宋体／衬线字。中英字体字重、行高和基线协调；字体运行时确认，不能假定某台机器上的字体路径永久存在。保留字形支持与字体来源。
- 标题、主要证据、字幕和辅助信息建立明确主次。字号按实际画幅与手机缩略显示检查，长词按语义重排，不能为挤进框里一路缩小。大面积留白只在确有阅读或构图作用时保留；信息不足时扩大主画面、重排或撤去空栏。
- 各容器边距、线条、字幕基线和小窗对齐；真人和资料等比呈现。少量分隔线用于分区，不加无意义页眉、身份注释、重复标题或装饰标签。

## 按任务使用版式

| 当前任务 | 画面组织 |
| --- | --- |
| 本人态度、连续口播 | 没有持续资料需要阅读时，真人可占主要画面；字幕和有用的语义强调延续同一系统，不为套网格把纯口播缩成小框 |
| 持续解读引用原片、文章或产品资料 | 横屏默认执行上方固定网格：左资料、右补充、右下真人、左下字幕；关键讲述处展示真实材料，不能把主资料区变成大段自制文字 |
| 话题较长、确需导航或补充 | 侧栏显示当前话题／总数、总结、补充或观点；不复制主屏文字与动效，不提前显示后文；按语义换卡，卡内保持稳定 |
| 明确步骤或流程节点 | 使用[全屏步骤文字蒙版](editing-methods/picture.md#V30)揭示当前步骤及必要说明；需要看操作时及时返回真实界面，不用文字页遮掉关键点击 |
| 鼠标操作或界面细节 | 保留完整界面，在真实鼠标／当前目标原位置聚焦，按[鼠标视觉重心](editing-methods/picture.md#V31)停稳、展示结果、恢复全景 |

真实操作优先保住完整界面与目标，不能为了套资料舞台裁掉按钮、文字或操作上下文。竖屏需按纵向安全区重新排资料、真人与双语字幕，保持同一主次与对齐，不直接套横屏坐标。用户本期明确选定其他布局时服从该选择；这些例外不另设一套与上方冲突的资料型横屏默认。

普通字幕默认透明背景。默认中英双语的层级、翻译和时间对齐按[双语字幕](bilingual-subtitles.md)执行；重点词的初态、发声锚点、邻字让位和强调保持以[网感 V24](editing-methods/text.md#V24)为唯一技法规则，不另写一套恢复行为。

## 动效和内容

默认同时执行[场景衔接与真实材料运动语法](screen-motion.md)，完整剪辑或较大动效返修时读取。它提供认可预告实值、每场四阶段、转场／资料选项，以及[语义趣味与惊喜](visual-principles.md#有语义的趣味与惊喜动效)、颜色分工与强弱错峰。主动为适合的原声落点选择主画面性格动作，不能只更新文字、套一批金框或做轻淡入；印章只是选项且标注创作者态度，不能冒充官方认证／原网页。

按语义、真实参考和阅读需要决定动作强度，不以固定秒数或效果种类配额分配。主要关系清楚、完成态可读即可保留强烈联动；信息密集时降低并发焦点，避免主屏、侧栏、字幕和背景同时争抢注意力。栏目字卡按内容换，不每次回放都重复同一套入场。

资料说到才出现，讲概念要给有依据的解释或例子；说平台、播放量、私信等时展示对应实际素材。区分原话、作者理解和补充科普，不把概括伪装成引用。没有用途的侧栏词条直接撤去。

## 不照搬参考片的内容参数

资料型横屏的几何按上方执行；对谈VS、具体人名和照片、日期、原片1.5倍、固定节目声增益、总时长一小时不属于布局默认。小窗按内容选择，纯口播和真实操作不强制常驻。封面按[封面与发布](covers-and-release.md)独立构图；用户明确要视频同款时再继承本色盘，不把所有封面自动变成黑底。

## 检查实际输出

检查普通段、最长标题、双语最长句、步骤切换、鼠标聚焦、资料进入退出和结尾。复查黑屏、异常空栏、文字碰撞、侧栏提前出现、重复动效、速度标签及上一个场景残留。原片停帧时真人小窗仍应沿本人原声时钟运动；不能因整幅变化小就误判卡死。最终检查范围与限制记入现有制作说明，不能用样片或单帧代替整片视听。

对资料型横屏再核对：左资料是否真正占主屏、右栏是否只有当前补充、真人是否落在右下且脸完整、字幕是否留在左主屏下方，以及各区是否按同一网格对齐。至少看首帧、资料切换、最长双语、强调峰值与结束，缩到约手机观看尺寸仍能辨认对象、读出当前重点；不能只用元素没有越界证明布局舒服。

动效另检查所有场景边界前后及每张资料的完整呈现过程，按[运动验收](screen-motion.md#在真正的成片中验收)看连续输出；漂亮的排版终帧不能证明转场自然，源工程中有动画也不能证明导出可见。
