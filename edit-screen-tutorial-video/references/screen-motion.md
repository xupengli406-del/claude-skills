# 默认运动语法：场景衔接与真实材料呈现

本文件用于电脑录屏、资料主屏和画中画讲解，与[屏幕构图](screen-layout.md)配合；真人现场为主的随手拍不继承这里的资料主屏。局部任务不重开整片。

执行HyperFrames时，house-style中“单一强调色／装饰持续运动”的通用创意建议不得覆盖用户选定的固定布局、真实资料可读性和本文件的语义色角色；安静阅读态不加循环环境动效，时间线与导出等工程约束仍依当前工具规范。

查找入口：[主体与占屏](#先保留本期主体与占屏关系)／[身份与布局](#多人身份与内容布局的核对)／[参考实值](#从认可参考实际取得的做法)／[场景四阶段](visual-principles.md#每个场景写清四个阶段)／[当前问题与关系](visual-principles.md#围绕当前问题组织关系)／[趣味与惊喜](visual-principles.md#有语义的趣味与惊喜动效)／[颜色与焦点](visual-principles.md#调色角色与同屏焦点)／[转场](#场景转场怎么选)／[真实资料](#真实图片长图与界面的内部呈现菜单)／[成片验收](#在真正的成片中验收)。

## 先保留本期主体与占屏关系

增强已有实拍的动画效果，默认是改善所选画面里的表达，不等于授权重排人物与资料的占屏关系。用户要求全屏真人／全屏现场时，现场底图持续覆盖整个画布，Logo、关系线、短标签和必要图形叠加其上；不能为了放大解释图而把人物缩进小窗、改成左右平铺或让不透明资料板取代现场。语义所需的切近、双人镜头和回全景可以沿用，全屏底图不等于每帧必须全员同框。

先按实际构图和镜头变化选择叠加锚区，避开人脸、关键手势与字幕，按原声分步演示，之后仅在稳定区域保留后文需要的少量提示。空间不足时简化图形或拆成连续步骤，不用缩小真人来迁就整张图；局部渐变等可读性处理不应遮成新的主屏。

本条用于保护本期已选布局，不禁止用户主动选择资料主屏、陪看小窗或上下分屏；这些模式仍执行各自规范。用户要求保留的旧呈现作为比较选项继续留存，新增变体不能自动替代它或被记为唯一最终接受。

## 多人身份与内容布局的核对

信息归属以当前实际发言、原片及已核准的发言时点为依据，不能从话题段落、主持角色或上一说话者推断本句是谁说的。多人初次介绍以已提供的姓名与必要身份帮助观众认人，核对文字数据、画面位置和实际出镜；不盲套固定称谓、补写未提供的学校／学历／成就。显示名、历史称谓及各处人物标签沿用一致身份来源或映射，避免多处硬编码漂移；显示名更新不改写真人原声或逐字字幕。

文字、底板与窗口按实际内容包围盒、内边距、基线和视觉中心适配，并放回整屏网格核对。相关组件在同一内容带有明确对齐与比例，信息区和真人区的各自尺度、相对位置与整组位置协调可辨；按本期选定的全屏／画中画／上下分屏等方式分配主次，不为了排图擅自改成另一形式或把真人缩得无法认人。居中、左对齐等按信息层级选择，不将一次“需要对齐”的反馈变成所有文字绝对居中的规则。

层级顺序与可读边界在入场、换词、缩放、持有和退出中都要成立。按完整字形与图形的可见外轮廓检查无意的文字互穿、图文相盖，标签与后期容器／装饰边界留清楚间距；用排布与层级解决碰撞，不只看元素中心或最终静帧，也不靠将正文压到难读来掩盖遮挡。

留白用于呼吸、层次与分组，区别于无意义预留槽、空Logo位或孤立大空块；拥挤与无效空白可以同时存在，应先重排内容组，不靠全填满、压小文字或缩小真人硬挤。标识完整可辨或有明确裁切意图，不能无意截成半个；实际没有Logo时不保留空占位。底色、材质和整体比例依据本期选择及现场适配，不由一次反馈固化成全局同色或禁用某种颜色。

日期、体验性质、姓名前缀等标签只在有独立观看用途时保留；同一信息框内观众已知道归属时，不重复堆称谓或显而易见的注释，也不把这些标签全局禁用。信息变化继续执行下方语义生命周期：给完成态实际阅读时间，沿当前对象和必要前文平顺交接，不随换词莫名跳位置或反复整页重置。

## 从认可参考实际取得的做法

已核对的参考是64.533秒、30fps的 `邵艾伦与孙宇晨_预告片_1080p.mp4`，对应工程 `scene_design.py` 与 `video/index.html`。以下是工程实值，坐标为原1280×720逻辑画布，1920×1080位置／距离乘1.5；时长不随分辨率缩放。

## 场景转场怎么选

参数为起步建议；落点由固定网格和素材本身决定，较大动作需先看连续输出。换的是舞台内容，不让固定主标题、字幕带、规则线与真人小窗跟着无意义地滑动。

| 关系与适用条件 | 起点 → 动作 → 落点／停留 | 应检查的结果 |
| --- | --- | --- |
| **章节推进、换一组材料** | 沿参考的右入左出：旧场向左退出，新场从右侧偏移进入，遮罩逐步打开；可从0.42秒重叠起步，最后精确落回标准舞台 | 中间有内容承接，方向一致，无黑／白空闪；新场停稳后关键内容完整 |
| **同一对象从全貌到细节** | 保留同一张真实图与可识别锚点，在共同坐标中推近／平移至目标，读完再退回或接邻近段落；不要把同图当新图突然重置 | 观众能跟随目标去向；焦点、圈线和图像同步，无露边、突跳与清晰度过度损失 |
| **同主题材料替换、情绪平顺接续** | 旧资料完成态→短交叉淡化或旧层淡出、新层移入→新资料稳定；可从0.18–0.35秒比较，文字密集页面不长时间双曝 | 没有两段正文互相叠成重影；新来源可辨，字幕与原声连续 |
| **从一个问题／对象揭示答案** | 以当前对象或目标区域为蒙版中心，矩形／圆形窗口从小到完整，下一幅真实材料接在窗口后；完毕撤掉过渡蒙版 | 收束／展开中心有语义，目标不被切半，不遗留半个圆、遮罩或空屏；细则按[V14/V17](editing-methods/picture.md#V14) |
| **对照、结果或明确语气转折** | 当前结论落住后自然硬切到结果，或先保留共同锚点再替换差异区域；不把所有语义转折都变成柔和淡化 | 切点保住完整话音；对照维度清楚，无故障帧，不凭拼接制造新因果 |
| **列举／流程逐步展开** | 已有完整基础结构→依发声揭示当项、移动当前选中态、连接下一节点→保留已讲关系，末项落定再退出 | 不提前泄露后文，不用空槽占位；完成后能读懂顺序与当前所在位置；明确步骤可用[V30](editing-methods/picture.md#V30) |

## 真实图片、长图与界面的内部呈现菜单

选择能解释这句话的处理，可在同一场联动使用；丰富来自可读的状态变化与真实细节，不来自换一批没有意义的动画名称。

| 材料／表达任务 | 可执行的观看过程与落点 | 使用边界与验收 |
| --- | --- | --- |
| 项目头图、产品外观、官方海报 | 首帧即识别对象；整体落定后按原声推近标题、产品或关键标识，再把结果留住。一次镜头落定可从全图1.02→1参考，明确细节推近按原生像素另定幅度 | 该轻微落定不能单独充当整片的动效丰富度；关键数字、原水印和主体完整，宣传图不冒充实测 |
| 原文长图、目录、报告 | 先建立页／章节上下文；在固定阅读窗口中按段落停靠，依讲述平移至下一段，选中行、圈线或下划线随焦点转移；每个停靠点有阅读时间 | 不把整张缩成邮票，不匀速滚到观众读不完；裁切／滚动位置记录，原文内容与顺序不改 |
| 图中关键句、数字或证据等级 | 从全图定位→目标框／下划线实际画出→当前区域保亮或可读放大→停稳→撤提示或回全貌；旁注在目标附近跟进 | 目标真实存在，不修改截图数字。界面／操作聚焦依[V31](editing-methods/picture.md#V31)同源同钟同位置，不另开无依据的重复窗口 |
| 两项产品、两种选择、前后状态 | 两份真实材料落在共同基线；按口播展开本次比较维度，差异以选中、连线、替换或局部揭示呈现，结论落定 | 不一起放大两边又让字幕同时抢焦点；材料版本与比较条件可核对，不生成假的对比截图 |
| 真实画面中的对象关系 | 保持图像为主，关系线从实际起点连到目标，箭头／标签按讲述接力，完成后关系仍可读 | 图形是解释层，必要时标为整理；不冒充原页面已有的线条或产品实际结构 |
| 阅读后回到本人／下一材料 | 收回临时圈线或恢复全貌，资料沿既定方向退场；真人按同一时钟连续发言，下一材料接住前一对象或当前问题 | 本人不因资料停帧而冻住；同一真人副本只留一路声音，没有闪现原录屏旧布局 |

## 各层分别做什么

| 层 | 运动任务与完成态 |
| --- | --- |
| 主资料 | 承担证据与观看过程：全貌、段落定位、细节、比较和返回。图片不只是文字卡背后的静态装饰 |
| 主标题／场景标题 | 外部主标题稳住整片身份；换题时按语义一次替换。场内短标题可用裁切向上揭示、尺度落定、盖章或分层接力，完成态准确可读，不能替代真实材料 |
| 侧栏 | 导航或补充在换题点更新，可随舞台内容统一移入／淡换一次后稳定，不叠加一次重复入场或逐字跳。当前高亮随话题移动；不重复演主屏全部动效、不预告未说内容、无用则撤去 |
| 真人 | 维持真实表情、口型与本人原声时钟；资料阅读时右下连续运动。进入／恢复主画面可做一次自然位移或尺度交接，不随每次字卡反复抖动、跳尺寸或推拉脸 |
| 中文／英文字幕 | 固定字幕区与中心，正常句先自然显示；重点词按[V24](editing-methods/text.md#V24)在真实发声时放大／变色／变形、邻字平滑让位，终态保持到本句退出。英文辅助层稳定；不能用字幕弹跳代替资料动效 |
| 圈线、标签、声音 | 指向主阅读目标并与动作落点联动；说明完成时撤去。声音按需且弱于人声，不把每次换图都配同一个嗖声 |

## 在真正的成片中验收

先做覆盖“场景交接＋真实材料内部变化＋字幕强调”的代表性短片。检查动画前、中、完成态、阅读停留、出场与下一场入场，不能只看漂亮终帧；随后按整片全部场景边界检查当前导出。

- **连续与自然：** 1×看前场结尾到后场完整停稳，追踪共同对象、方向和阅读顺序；无空闪、叠字、跳位、突然换回旧版式、声音断点或重复声。
- **确实在动：** 真实资料的关注位置／状态及圈线关系在相应口播处变化；不是整片只剩文字替换和轻淡入。若用户看不出，重做具体视觉过程，不只改成“丰富版”文件名。
- **趣味和调色确实服务发言：** 看动作进入、峰值、接触／揭示、完成态与其后安静画面；能说清为什么此处盖章、贴旁批、翻转或接力，且来源／个人注释分明。检查旧框退场和颜色角色，不能主画面、侧栏、字幕与真人外框各有一处同权闪动；修正竞争不削弱V24句末保持。
- **入场峰值不裁边：** 对印章／纸签等资料窗口内注释，逐帧检查初次可见、最大尺度、最大旋转与回弹经过的完整外轮廓、描边和阴影；安全边距按变换后范围及视窗裁切计算，不能只查静态容器或落定帧。默认完整入镜，用户明确选择裁边效果时才按该效果验收。
- **可读与同步：** 手机尺度看目标、最长双语、强调峰值、长图停靠；读图时有稳定停留。真人、原片及同步副本按各自源时钟推进，冻结仅作用于计划中的真实资料，不冻住本人。
- **可复现：** 顺序播放、随机跳转、分段渲染的同一时刻一致；后文元素未提前显示，退场对象无残留，蒙版和强调终态正确。引擎参数以本次工具为准，不直接依赖网页hover或实时回调。
- **诚实记录：** 实现、导出、实际观看／试听与用户接受分开。连续帧可证明运动，不能代替正常速度视听；没有实际听觉能力时明确该限制。

## 趣味动效研究依据与迁移边界

2026-10-15研究：
