# 先看观众主要在看什么

只在完整制作开始前确定一次流程负责人，依据真实素材的主要画面及观看任务，不按坐姿、是否面对电脑或有没有脸判断。

| 主要观看对象或明确请求 | 流程 |
| --- | --- |
| 本人表情、现场与观点表达；即使坐在电脑前也主要看本人 | 真人随手拍口播 `edit-talking-head-social-video` |
| 电脑操作、原片、文章或资料承载主要解释；本人可在小窗 | 电脑录屏与资料讲解 `edit-screen-tutorial-video` |
| 明确要求连续手写画布、真实逐笔与右侧笔记 | 画板手绘 `produce-whiteboard-talking-head-video` |
| 多人的真实提问、回答、追问与互动是主体 | 多人访谈 `edit-multi-person-interview-video` |
| 无真人的信息图形与本人录音/授权旁白；或明确数字人 | 原声MG或数字人各自的独立流程 |

## 旧入口与一次分流

旧key继续有效。通过旧真人入口接到屏幕主导素材时，在制作前一次性交给录屏/资料流程，携带已选画面、素材、最终原声及范围。本次已经确定负责人后，不让两包反复调用对方整套流程；误送到不匹配包时由最外层按此表重选，而不是包内递归。

## 混合片与局部范围

混合片不是第三个Skill。按主要观看任务确定负责人，逐段标注真人、屏幕或资料，并在同一母音频和剪辑映射上切换。两类局部构图与共同规范都在包内，不为切换片段另造音轨、时码、稿件或发布包。

明确只改字幕、封面、声音或已选画面中的某一层时，先遵守范围，不借分流重做整片。已有白板、访谈或已选构图保持专项规则，除非用户本次明确更换。
