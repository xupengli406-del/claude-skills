# 引用原片与本人解读

当主要观看对象是引用原片、屏幕或资料，本人以可选画中画解读时使用本分支。按[屏幕构图](screen-layout.md)和本期选择执行；短引用不自动改变真人现场主角。

## 先组织理解链，再压时长

按话题梳理“相关原片／证据 → 本人理解或质疑 → 必要补充／结论”。每段观点对应其依赖的提问、论点、例子和限定。保留让没看过原片的人也能理解的上下文，不能只保留作者评论、把评论依据全部剪掉；也不必完整保留整场访谈。

先去没有观点或上下文依赖的长原片、操作等待、失败重说、重复总结与绕回。每次删后检查指代、因果、否定、主语和例子的承接，接缝前后连读。残留半句、尾词和卡壳是待修问题，不能用字幕或动效掩盖。字幕跟随最终保留的真实原声。

用户明确锁定的稿件／原声范围记录为受保护段；不为缩时长擅删其独有内容，补录接在用户指定语义位置。对允许精剪的现场表达，保留完整观点与本人语气，去冗余而不机械逐字复原稿件。后续明确授权可覆盖早期锁定。

开头可前置有代表性的真实原声，再接开场；核对它与封面承诺、本人立场及正文兑现一致。跨时间摘选须保持每句话的原意和源时间，不把省略后的蒙太奇假装成无间隔对答。

## 声音与三路时钟

执行[声音主次、原片/本人/成片映射与变速](audio-state-and-mapping.md)。这里负责资料陪看的理解链与版式，不复制第二套声音规则。

## 侧栏和章节

主屏展示当前引用或证据，字幕服务当前重点发言，侧栏只做导航、总结、补充或观点。话题标题配当前序号／总数，换题后同步更新；没有有用信息就调整版式，不用空洞词条占位。侧栏整卡按语义更新，其余时间静止，不复制主屏强调动效。

本片经过摘选时在适当说明处与封面／发布文案写明“精华版”“已摘取精华部分”等定位；“原访谈四小时”不等于成片包含完整四小时。术语科普取自可核对的来源，作者理解另列。说原片所在平台时展示对应真实截图，不让说明与画面脱节。

完整长片交付默认包含可复制的章节目录，每行“HH:MM:SS 标题”，来自当前最终成片时钟。章节可合并过短的钩子／开场，保留主要话题导航；间隔与数量按本次平台编辑器要求检查。删段或变速后重算，不能用原片时间或旧版目录。切片候选按能独立理解的论证单元标记，不自动生成额外视频或代发。

## 验证和复现

在既有剪辑计划或制作说明中补观点依赖、三路时间映射、声音状态及侧栏更新点即可，不新建多套平行表格。检查真正导出的版本：关键原片前提仍在、本人说话时没有第二条抢话线、气口不反弹节目声、冻结没有冻住本人、补录和变速后字幕不漂移、信息卡和1.5×等播放器提示没有串场。音量、相关性或结构校验通过不等于正常速度主观试听；检查范围与未完成项如实记录。
