# 真人随手拍的画面主体

以真实的人、现场与表达为主画面，沿用原片画幅、人物尺度和拍摄关系。自拍、走路、固定机位、坐在电脑前讲观点，都按实际观看对象判断；坐姿不是分流条件。

- 保留人脸、眼神、手势、口型和现场线索。解释层放在真实空处，必要资料短暂进入后自然回到当前主体；不为容纳文字把已选全屏真人缩成小窗。
- 原素材稳定、清楚时不额外制造运镜。按真实发言在重点处做可辨认的动作或图形，完成态可读；不持续推拉脸，不把字卡堆成主画面。
- 普通字幕透明，中文主层与英文辅助层共用最终原声时轴。给V24放大后的真实宽高留空间，避免嘴部、手势、产品及平台遮挡。
- 屏幕或资料开始承担主要解释时，对应片段可用本包[屏幕构图](screen-layout.md)，保持同一母音频与源到成片映射，不重复生成声音。整片主要看屏幕时，首次分流就选择录屏/资料流程。
- 白板、多人访谈与数字人保留各自已选主体和布局；本页不把它们改成随手拍。局部字幕、封面或已选作品返修只改授权范围。

具体动作读[真人动效](person-motion.md)。参数是试排起点，实际手机尺度和连续导出检查决定是否成立。
