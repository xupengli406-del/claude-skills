# 字幕分层与画面回应

本页承接真人口播 Skill 的短句分层规范（同步于 2026-09-24），在没有原 Skill 时也可独立执行。数字人出镜不改变字幕对原声负责的原则。

## 先标语义，再排字

1. 用实际音频识别/对齐拿到词句时间，校对专名、否定词、数字和停顿。不能按字符数均分时长。
2. 普通句保留基准字号；铺垫约为基准的 **0.75–0.9 倍**；判断、反差、动作或结论中的重点短语约为 **1.25–1.5 倍**。不是每句话都放大。
3. 先选少量确实有意义的重点，判断当时主动画是否也在变化。画面复杂时让字幕稳定，不能把强调密度或固定秒数当效果指标。
4. 按语义与真实字形宽度排成一至两行，不把“参考图”“画面合成”或产品名称拆散，不留孤字。太长时缩短同屏片段或重排，不能无限缩小字号。
5. 字幕忠于原声。摘要、注解、事实补充应放另一层级，不伪装成说过的话。

## 视觉基线

- 真人/数字人底片默认暖白字配一种强调色；透明背景、细描边或轻阴影适应明暗。浅色 MG 画布可用炭黑正文与同一套陶土强调色，先确保手机对比度。
- 基准大小按当前画布和平台安全区确定。例如1080×1920画面可从约50–53px起步；铺垫与重点使用相对比例，而非照抄某个字号。
- 变色、放大、下划线选一至两种；可适当加粗或微斜。普通字幕不用封面式厚黑字壳、实色底板、连续抖动。
- 字幕位置与阅读路径稳定；检查最长句、两行句、人物全屏和小窗场景。不能压住脸、证据重点、动作落点或平台按钮。

## 短句接力

先出现真实说到的铺垫，重点短语在自己的发声时间出现。铺垫可短暂留在上行，重点接在下行；不要一开始就把整句的重音词都亮出来，也不逐字蹦跳。

一个短语只做一次轻量进入或强调，然后稳定停留供阅读。入场可从约0.16–0.25秒起步，不能为了动效缩短可读时间；常规短句尽量留足约0.65秒以上，长句按实际阅读需求延长或重新分组。这不是修改旁白节奏的理由。

同一句已在主画面大字呈现，不在底部重复一整遍；保留原始 SRT，展示层记录由哪处图形承接原话。不能单纯删字幕而让原话在屏幕上消失。

## 画面回应原声

讲实例时展示可读的真实证据；讲具体要求时聚焦相关句子；讲回到本人时让资料退场、恢复人物。优先让资料、圈线和关键词变化，避免连续推拉近景人脸。

“放大”“圈一下”等演示以实际重读词为锚点，必须有可见初态、过程、完成态和读图停留。不要在首次出现时已经是终态。若需要提示音，只落在有解释意义的一个动作上，弱于人声。后期对齐效果不能宣称实时操控。

保留有用上下文，不为“新信息”每句话清屏。一次只给一个主要变化；正文的完整解释与开头高光可以同时保留。

## 模板接口

随包 Remotion 的 `SemanticCaptions.jsx` 默认支持普通字幕与短语分层。普通 cue 仍使用 `start/end/text`。重点 cue 增加：

```json
{
  "start": 4.0,
  "end": 7.8,
  "text": "人物和资料在同一画面里接续",
  "emphasis": {
    "lead": "人物和资料",
    "focus": "在同一画面里接续",
    "key": "同一画面",
    "at": 5.2,
    "ratio": 1.28,
    "timingSource": "reviewed-word-alignment"
  }
}
```

这是接口示意时间，真实任务必须换成实际词级时间。`lead + focus` 必须与 `text` 的原话一致，`key` 必须属于 `focus`；`at` 是后半短语实际开口时点。没有词级对齐就先用普通字幕，不编造精准锚点。

若主画面承接同一句，用 `display: "graphic"` 并记录 `graphicText`，确认该句在该时间窗确实可读。只对展示层去重，SRT 保留完整原话。

所有样式由绝对帧时间计算，跳到某帧与连续播放得到同一状态。后出现的短语、图形初态隐藏，不被未来动画提前露出。模板的无声示例时间仅演示接口，不是对实际旁白的对齐证明。

## 验收

- 导出有代表性的15–30秒，包含普通→重点→普通、完整入场和落定。沿用已确认风格时内部验证后直接继续，不重复索要确认。
- 在手机尺寸检查最长句、最短句、两行句、人物背景与浅色背景；逐帧看重音前/中/后，确认未来词不抢跑、没有孤字或突然跳位。
- 实际看连续运动；截图只能证明排版。若没有完整听审，明确范围，不把ASR、波形和文件检查称作听过。
- 字幕专门返修时，复用已认可配音、人像、主动画时序；若素材烘焙了旧字幕，从可编辑源重渲染字幕层，不能叠两套字幕或用色块遮挡人物。
