# 默认封面：大标题真人

沿用真人口播的封面规范。它独立于片内MG色盘：视频克制、统一，不代表封面必须变成小字说明页。用户本期明确指定其他方向时遵守该方向。已选成片不因制作封面重做声音或画面。

## 先确定点开的理由

从完整稿件简记：谁会看；观看前的问题或期待；看完带走什么判断/方法；正文哪段兑现。主标题让主题对象和观看理由同时可识别，不只反映作者经历或堆工具名。允许个人结论先行，不能捏造实测、时间、费用、免费额度或保证效果。

## 当期选择优先

原真人口播默认“大字压真人”是一种已验证方向，不是覆盖用户每期选择的硬约束。用户指定 L 型、顶部＋底部或其他布局时，保留粗字、主副层级和手机识别度，按指定区域排字；若要求完整脸部清楚，真实脸部区域就是避让区，不能再以默认允许压下半脸为理由覆盖。不要把某条示例文案、衣服或人像姿势固化成所有人的模板。

## 五项视觉要求

1. **近景自然本人。** 用户已选的准确照片/帧优先；没有选图则使用本人授权原照或当前清楚自然的帧。新生成以真人原照锁定身份，旧封面只做风格参考。保持眼神、皮肤与表情自然，不换脸、不卡通化，也不强制商务造型。
2. **人物轮廓描边。** 沿头发、耳朵、肩臂的实际外轮廓加清楚暖黄/暖白或本期合适颜色，不能只是照片外面画矩形，也不能只给文字描边。透明素材须检查真实alpha和边缘，不允许烘焙棋盘格。
3. **大字压在人像上。** 厚重、清楚的中文展示字体直接叠在下半脸、肩胸；保留眉眼身份。不要为了避开整张脸把人缩小、把字全部推到空白侧栏。不是简单“把字放大”：文字、人像和轮廓需要有明确前后层级。
4. **主次和分色。** 一组显著主题、一个观看理由；用字号和少量暖白/奶油黄等颜色区分层级，适量深色描边和短硬阴影保证对比；标题可用更醒目的描边，但不能把这种厚重封面字壳套到片内普通字幕上。主题对象不能只在角落的小标签里。文字连贯，别把中文词组或Skill等专名拆散。
5. **比例独立设计。** 默认只出3:4与4:3。横版重新安排人像尺度和阅读顺序，大字仍可跨过人像；不能裁竖版、留空边，或把正文缩在一角。近景没有手时不强塞道具；有道具时单一明确，手与接触处真实完整。

## 字体与背景

选厚重、清楚的中文展示黑体，主标题可用暖白/奶油黄配黑色描边和短阴影，主副字号形成差异。背景是承托本人和文字的真实空间：降低杂物、明暗和饱和度竞争，保持自然肤色，不堆无关AI电路、霓虹或装饰标签。参考图只提取字形与构图气质，不换参考图里的人，也不复制无关标题。用户已选具体字体/背景方向时优先匹配。

## 制作与测量

有可用的`produce-big-title-cover`时读取其当前规则；未安装时本页和随包检查脚本可独立执行，不要求接收者安装作者整套Skill。

先用图像生成/编辑能力做无字主视觉，明确身份锚点、姿态和实际轮廓；中文标题与品牌文字用HTML/CSS/Canvas/SVG确定性排字。需要抠像或改照片时使用当前环境的图像编辑能力，不能用错误人像或不准确轮廓凑数。

建议在1242×1656、1600×1200的设计坐标上布局，以2倍分辨率直接绘制文字，导出2484×3312和3200×2400 PNG。照片细节仍受原素材限制，不能把放大叫作获得新细节。字体使用获授权的中文展示黑体，公开Skill不分发系统字体。

加载字体后测量实际字形范围，计入描边、阴影、旋转。在源旁保存排版JSON：

```json
{
  "canvas": [2484,3312],
  "image_sha256": "本次输出PNG的真实哈希",
  "safe_rect": [80,80,2324,3152],
  "keepouts": [{"id":"eyes","rect":[700,900,1000,280]}],
  "blocks": [{
    "id":"title", "text":"完整标题", "atomic":["标题"],
    "runs":[{"text":"完整标题","flow":"title","line":0,"rect":[100,200,1200,300]}]
  }]
}
```

以上坐标是schema示意，不能直接当测量结果。keepouts按本图与本期选择设置：默认保护眉眼、手势和接触处；选择L型避脸则保护完整脸部。已授权叠字时不使用整个人物大框否决合理构图。每句对应一个block，runs按真实阅读顺序，不把一句拆成几个block绕过语义检查。rect格式为[x,y,width,height]。

```sh
python3 scripts/validate_typography.py path/to/layout.json --image path/to/cover.png
python3 scripts/validate_cover_set.py path/to/delivery --topic "本期主题"
```

## 验收与交付

原尺寸和300–400px宽缩略图都实际查看：先看懂主题与理由，再认出本人；轮廓描边确实存在；文字与人物的前后层级符合当期方向，默认叠字保留眉眼、L型避脸保持整脸清楚；没有糊字、拆词、身份漂移、错误手势、意外切边。字体/尺寸检查不证明审美或点击率。

成片、封面、标题必须同主题。新封面替换已拒绝版本后重建发布ZIP，逐文件核对并按授权可恢复清理旧封面及独占源。保留当前排版、无字主视觉、必要测量和一个发布目录。

检查脚本源于`produce-big-title-cover`，仅做确定性检查。许可证见[cover-helpers-license.txt](cover-helpers-license.txt)，不包含其作者或任何用户的人像。
