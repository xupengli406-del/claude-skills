# 丧尸清道夫复古未来封面

生成“阳光、浪漫、荒诞、非血腥”的原子时代末世封面。复刻的是版式、色彩、材质和叙事语法，不复制参考图中的品牌、署名、具体文案、播放器界面或角色身份。

字体是本风格的第一视觉锚点，优先级高于背景道具。`standing-poster` 默认采用“上红下黑”的双层标题，不得退化成普通单色黑体。

## 输入解析

从自然语言提取：`topic`、`headline`、`subheadline`、`layout`、`aspect_ratio`、`platform`、`must_include`、`must_avoid`。只有 `topic` 必填；其余缺省时直接采用以下默认值，不因非关键细节停下来追问：

- 标题：自动拟定 3 个短标题，选画面性最强且不超过 10 个中文字的一条；站立版把标题拆为 `红色主题词|黑色类型词` 两层。
- 布局：角色亮相用 `standing-poster`；关系、故事或章节内容用 `sofa-tableau`。
- 画布：横版封面默认 16:9；竖版必须重新构图，不得中心裁切横图。
- 角色：拾荒服务机器人、成年复古人偶女性、鸵鸟或同类高瘦荒诞动物。
- 氛围：幽默、浪漫、冒险、明亮白天、非恐怖。

## 生产流程

从 GitHub 仓库安装后，若存在 `assets/.parts/manifest.json` 且字体或参考图尚未还原，先运行 `python3 scripts/restore_assets.py`；脚本会无损拼接并校验 SHA-256。正常本地安装已包含完整素材时无需执行。

1. 先生成无字底图。使用内置图像生成工具，把 `assets/reference-standing.png` 与 `assets/reference-seated.png` 仅作为风格/构图参考；明确忽略其中所有 UI、播放按钮、Logo、水印和现成文字。
2. 底图必须给标题区留低纹理负空间；广告牌、路牌和纸条保持空白或不可辨识纹理。禁止让模型生成最终标题。
3. 检查底图的角色身份、叙事接触、头部高低节奏、标题留白和远近层级。底图采用哪种模板，排版必须使用同名模板；禁止把 `sofa-tableau` 标题框叠到 `standing-poster` 底图。底图不合格时只修最低分的一至两项。
4. 用 `scripts/compose_cover.py` 确定性叠加实心标题、描边、硬阴影、浅弧与纸条。英文上行在 macOS 首选 Impact，跨平台回退到随 Skill 分发的 Bowlby One SC；下行固定使用 Anton。中文固定首选随 Skill 分发的 Noto Sans CJK SC Black，视觉字重为 Black/ExtraBlack（约 850–900）；只有缺少该字体时才对兜底字体做同色实心扩墨，不得用异色颗粒或磨损。若标题要与帽檐、动物头或肩部产生层叠，必须提供 `--foreground-mask`，把人物重新合成到标题上方；没有遮罩时只能使用不碰脸的安全标题区。优先调用 `load_workspace_dependencies` 返回的 Python；若环境没有 Pillow，再使用具有 Pillow 的 Python 环境。
5. 同时输出完整封面、320px 缩略图和布局元数据。缩略图上标题和三角色轮廓必须仍可辨识。
6. 按量表自评；低于 85 分或出现致命缺陷不得宣称完成。每轮只修改最低分的一至两项，最多三轮；连续两轮提升少于 3 分时切换版式。

## 固定不变量

- 16:9 母版中，主标题宽度至少为画布的 35%，主体人物或紧密群像高度至少为 70%。
- 站立版标题上行必须为砖红 `#952819`，下行为暖炭黑 `#1D1610`，两行共同使用奶油描边 `#DFCBAA` 与右下硬阴影；上、下行宽度比约为 `100:86`。
- 上行采用 ExtraBlack 宽体广告字，视觉字重约 900；下行采用 Black 高窄广告字，视觉字重约 850–900。两行不是同一字体等比缩放。
- 英文标题默认使用浅上拱：上行弧高约为行高 7.2%，下行约 5.2%，再叠加整组逆时针旋转；不得弯成半圆、波浪或综艺花字。
- 标题可以被帽檐、肩部或动物头少量压住，但标题绝不能压住机器人、人偶或动物的眼睛、嘴和主要脸部；有重叠时人物必须处于前景层。
- 标题填充必须是连续实心色块；禁止奶油色斑点、穿孔、大片掉墨或会破坏字面完整性的 distress texture。
- 标题、机器人脸、人偶脸、动物头形成三角或菱形，不能齐平排队。
- 角色之间必须有搭肩、依靠、遮挡或共同承载物等叙事联系。
- 至少四层空间：前景道具、中景人物、远景城市、天空；远景对比度低于人物。
- 青绿、砖红、暖奶油、炭黑、皮革棕为主色；荧光屏幕色不超过 2%。
- 旧化集中在边缘、接缝、握持区和受晒面，禁止均匀噪点滤镜。
- 动物头可像参考图一样压住下行标题末端不超过 4%，但不得遮挡关键字义；机器人脸和人偶脸绝不与标题相撞。
- 不得出现血浆腐尸、真人皮肤毛孔、现代战斗机甲、夜间赛博朋克、品牌、水印、乱码、播放器或应用界面。
