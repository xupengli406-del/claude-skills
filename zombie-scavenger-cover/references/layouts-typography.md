## 标题系统

始终采用“无字底图 + 后期合成”。主标题最多两行，建议 2–10 个中文字或 2–4 个英文短词。站立双行标题组逆时针旋转 2–3°，sofa 单行长标题约 5°；双行采用负行距并略微错位。英文主标题不是纯直线：整行描边、填色与阴影共同沿浅上拱曲线变形，然后再做整体旋转。

参考图像素取样后的标题色中心为：砖红 `#952819`、奶油描边 `#DFCBAA`、暖炭黑 `#1D1610`。这些是经过颗粒与旧化后的可见目标色；最终图像中各通道偏差宜控制在约 ±12。

### 主标题 A：红色英雄行

- 上行砖红填充 `#952819`，宽重、块面大、内部空间小。
- 下行暖炭黑填充 `#1D1610`，比上行窄约 14%，高度约为上行的 66%。
- 两行共用奶油粗描边 `#DFCBAA` 与暖炭黑右下硬阴影。
- 上行占标题框宽度 100%，下行约 86%，下行向右缩进约 2.2%W。
- 上行高度约 23.5%H，下行约 15.5%H；下行起点约在上行起点下方 21.5%H，形成轻微压叠。

### 主标题 B：高窄宣传行

- 全大写或重黑中文，高度大、宽度压缩、整组旋转约 `-3°`。
- 红色填充，深褐/黑色硬阴影；下方可加脏奶油纸条副标题。

### 字体栈

- 英文上行在 macOS 固定首选系统 `Impact.ttf`，再横向拉宽到标题框 100%；它的超粗窄体骨架、椭圆 O、低开口 B 和紧凑 M 更接近参考图。跨平台缺少 Impact 时，使用随 Skill 分发的 `BowlbyOneSC-Regular.ttf`。
- 英文下行固定首选随 Skill 分发的 `assets/fonts/Anton-Regular.ttf`；其高窄广告字骨架用于类型词。
- 中文目标不是普通 Bold，而是 `Black/ExtraBlack` 的约 900 级视觉重量。固定首选随 Skill 分发的 `assets/fonts/NotoSansCJKsc-Black.otf`；其方头、粗横竖与紧字腔更接近参考图中的中文海报黑体。只有字体缺失、回退到系统 Medium 时，才用同色实心扩墨约行高 1.4%，再按上行 100%、下行 86% 的宽度形变。
- 不使用圆体、手写体、互联网综艺花字或轻量几何无衬线。

## 字重与几何规格

| 项目 | 上行红字 | 下行黑字 |
|---|---:|---:|
| 字体类别 | ExtraBlack 宽体广告字 | Black 高窄广告字 |
| 视觉字重 | 约 900 | 约 850–900 |
| 标题框宽度 | 100% | 86% |
| 画布字高 | 23.5%H | 15.5%H |
| 左侧缩进 | 0 | 约 2.2%W |
| 字距观感 | 紧，约 `-0.01em` | 更紧，约 `-0.02em` |
| 垂直关系 | 基准行 | 下行起点在上行起点下方约 21.5%H，形成约 2%H 压叠 |
| 填充 | 实心砖红 | 实心暖炭黑 |

不要把两行当作同一字体仅缩小：上行必须宽重，下行必须高窄，二者的反差本身就是系列识别度。

## 英文浅弧规格

- 弧型：中心略高、两端略低的单一上拱，不使用 S 形、波浪或逐字随机跳动。
- 上行弧高：约行高 `7.2%`；下行约为上行弧度的 `72%`，即约行高 `5.2%`。
- 单行 sofa 标题：默认弧高约行高 `7.2%`，再叠加 `5°` 逆时针旋转，形成参考图向右上方扬起的动势。
- 描边、实心填色和硬阴影必须作为一个整体同步弯曲，不能只弯字面。
- 可用 `--arc 0` 关闭，也可在 `0–0.18` 内调整；超过 `0.10` 通常会失去纸浆科幻海报感。

## 人物与标题层级

- 原图的关键不是零重叠，而是正确的 Z 轴：天空/建筑 → 标题 → 帽檐、肩部或动物头 → 脸部细节。
- 机器人、人偶和动物的眼睛、嘴及主要脸部是绝对保护区，标题像素不得覆盖。
- 需要层叠时，为帽檐、头部、肩部或动物头准备白色/不透明前景遮罩，并使用 `--foreground-mask mask.png`；脚本会把遮罩内的原底图重新合成到标题上方。
- 没有前景遮罩时，只能使用模板安全标题区，不能靠“文字透明一点”掩饰碰撞。
- 动物头压住标题末端仍不得超过标题面积 4%；这是喜剧标点，不是遮脸许可。

系统可用的 macOS 兜底字体：`/System/Library/Fonts/Supplemental/DIN Condensed Bold.ttf`、`/System/Library/Fonts/Supplemental/Impact.ttf`、`/System/Library/Fonts/STHeiti Medium.ttc`。

## 1920×1080 基准

- 安全边距：72–110px；右下 10%W×10%H 不放关键信息。
- 上行字高约 23–25%H；下行约 15–17%H。
- 奶油描边约 0.7%H；硬阴影偏移约 1.0%H。
- 小说明低于 32–38px 时只作为纹理，不承载必要信息。
- 标题内部保持实心。旧感只来自低饱和目标色、轻微边缘不齐、硬阴影和全图细颗粒；不得在字面制造奶油色孔洞或明显斑点。

## 缩略图验收

- 缩到 192×108 仍能辨认红标题、黑脸机器人、红裙人偶、细长动物四个轮廓/色块。
- 320–360px 宽时主标题无需放大即可读出。
- 灰度模糊后前三个显著区域应是标题、机器人脸、人偶/动物头，而非背景建筑。
- 机器人和人偶面部不得遮挡标题。动物头可作为喜剧标点压住下行末端，但重叠不得超过标题面积 4%，且不能影响标题识别。
