# Prompt Patterns

## Mother image

```text
Create a brand-new original mono-color editorial image, <ratio>, flat front-facing page.
Substrate: <neutral substrate and hex>.
Ink mode: <one-ink or assigned two-ink pair with hex values and separate plate roles>.
Subject: <one recognizable person, object, scene, or relationship>.
Composition: <layout family>, <dominant scale>, <one focal event>, <one release zone>, <visible exposed paper>.
Display text exactly “<two-to-eight-word phrase>” in <type voice>, visibly related to the subject.
No other text. No numbers, dates, labels, serials, badges, logos, signatures, borders, QR codes, watermarks, or fake metadata.
Do not copy any supplied reference artwork, wording, or composition.
```

## Application image

```text
Use the supplied mother image as the exact artwork reference.
Create a clean, media-ready <carrier> application image in <ratio>.
Apply the artwork so it physically follows <folds, seams, panels, corners, ribs, architecture, or surface depth>.
Preserve the dominant subject, ink roles, focal composition, halftone character, and exact display phrase.
Use a restrained real-world environment that shows scale without competing with the artwork.
No extra graphic, brand, route number, product label, price, sponsor, caption, badge, QR code, or watermark.
The supplied artwork is the only printed content.
```

## Correction pass

For a cropped or misspelled phrase, edit only the artwork placement or text scale. Lock the carrier, subject, pose, environment, lighting, colors, and crop. Regenerate the whole application only when ratio or carrier geometry is fundamentally wrong.
