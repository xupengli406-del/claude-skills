# Coverage Matrix

Use this reference only for multi-pair planning. Do not force these exact examples when the user supplies different subjects.

## Mother-image diversity

For nine pairs, cover all rows at least once and avoid repeating one row more than twice:

| Axis | Useful contrasts |
|---|---|
| Human presence | portrait, partial body, crowd, no person |
| Environment | street, interior, natural landscape, stage, abstract paper space |
| Cultural register | fashion, architecture, music, travel, domestic object, ecology |
| Information density | extreme minimal, balanced editorial, deliberate maximalism |
| Scale | face detail, single object, room, street, mountain, building facade |
| Motion | still, walking, driving, wind, performance, suspended gesture |
| Composition | image field, type declaration, overprint collage, archival plate, journal, cover |
| Type voice | cultural grotesk, condensed civic, literary serif, typographic object, rotated display |

## Application diversity

Use distinct carrier classes rather than nine conventional posters:

- garment or wearable;
- moving public object such as a tram;
- packaging or vessel;
- interior textile or furniture surface;
- architectural wall or wallpaper;
- publishing or music object;
- outdoor equipment;
- travel object;
- digital projection or large public installation.

## Sequence rhythm

Arrange pairs so the viewer repeatedly gets a reset:

1. accessible human subject;
2. wide public scene;
3. culture or architecture;
4. extreme minimalism;
5. extreme maximalism;
6. crowd or performance;
7. landscape;
8. travel or movement;
9. spatial finale.

This is a pacing model, not a mandatory topic list.
